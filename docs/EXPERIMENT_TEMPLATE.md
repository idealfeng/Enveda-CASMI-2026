# 实验模板：YYYYMMDD_路线_编号

- 状态：planned / running / complete / failed / superseded。
- 假设与已有反证：链接LESSONS中的相关条目。
- 对照：正式提交编号、配方路径、Public分、源码SHA；固定哪些输入/候选/模型。
- 唯一改动：具体新信息、训练目标或处理阶段；整版复现列清全部变化。
- 模型：实际路径、SHA、配置/预处理、checkpoint步数和训练数据来源。
- 评价边界：官方身份、指标/截断、候选召回、参考隔离、预训练曝光；组件还是全流水线。
- 运行命令与预算：环境、seed、500步测速（若训练）、时间/内存上限。
- 输出目录：`runs/YYYYMMDD_路线_编号/`；保留配置、日志、模型、指标与失败信息。
- 报告目录：`reports/YYYYMMDD_路线_编号/`；日志和大型数组不要堆到项目根目录。
- 结果：正负变化、是否复验、Kaggle正式编号及状态。PENDING留空分数。
- 决策：采用/停止/需补证据，写适用边界和允许再启动的具体条件。
- 保留级别：冠军/正式提交/训练源模型/诊断证据保留；可重建缓存另列清单。

结束后更新EXPERIMENTS、LESSONS；真实创新高再写提升账本，执行模型/提交索引刷新命令。
