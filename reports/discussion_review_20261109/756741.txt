I've been thinking about this quite a bit, and data seems to be the critical factor in this competition.

My initial goal was to see whether the spectrum contains sufficient signal to distinguish structural isomers. Following the recommendation of a Claude agent, I approached this as a forward problem (predicting the mass spectrum from a molecular graph). For this to work, the predicted spectrum must diverge from the ground truth when given a decoy isomer, while matching it closely for the true structure.

To test this, I trained a model called GS_egnn, which is documented in my notebook (https://www.kaggle.com/code/toasthink/casmi26-gs-egnn-analysis?scriptVersionId=366571609).

Currently, the true structure achieves a higher spectral match score than decoys in only about 35% of cases. And, for the true structure, the predicted spectrum reaches an average similarity of around 0.85 on the main peaks. (This suggests it could potentially be used to rank candidate molecular structures generated by others.) Based on the current input features, there does seem to be an identifiable difference between the spectra of true structures and decoys.

The current input features are as follows:


Atom features: Element type, hydrogen count, degree/valence, formal charge, ring membership, ring size

Bond features: Bond type (single, double, etc.), ring membership, conjugation


These are encoded into node and edge feature vectors, and a GNN infers fragment probabilities. The model simply learns a statistical approximation of all the underlying physicochemical phenomena in collision-induced dissociation (CID). Consequently, if the local bonding environment shifts outside the training distribution, its predictive accuracy drops.

I have been trying to push this model further, but I find myself stuck on several fundamental questions:


How much of the known CID process can the current input features actually explain? What critical physics/chemistry are they failing to capture?


Even if the input features were theoretically sufficient to describe these chemical phenomena, how can we prevent performance degradation when encountering unseen or outlier bonding environments?


If the answer to question 2 cannot be resolved purely through deep learning architecture tweaks, an ab initio quantum mechanical approach (mapping the potential energy surface across all configuration space alongside collision dynamics) would theoretically be the ground-truth solution for the forward problem. Is there a viable hybrid approach combining quantum calculations with deep learning that makes this computationally tractable?



My current takeaway is that full quantum chemical simulations are computationally prohibitive within a realistic timeframe, making the refinement of statistical methods far more practical. Within the constraints of a competition, scaling up the data might be the only viable path to winning. Still, I hold a faint hope that an effective hybrid method might exist.

I would really appreciate any insights or feedback on this!
