Comment: Shehab Alshehabi

Hi. I believe that "Notebook Threw Exception" means that a notebook cell produced an error and that the issue was not with the grader - I think that would show up as "Submission Scoring Error". I'm not an organiser so I might be wrong about this.

I would first make sure you are not running out of memory. I would try to process:


A very large molecule (1159 Da is the largest molecule on the real test whereas 157 Da is the largest on the placeholder)

A molecule many spectra (16 is the largest in the test set and 9 is the most in the placeholder)

A molecule with all 10 adducts (7 is the maximum in train)

All the above at the same time


In order to run these tests, you can find molecules from the training data or just mash spectra together since we are trying to catch a crash rather than a logic issue.

To look for python errors, I would try to process:


A molecule with a very large mass that isn't in any database.

A molecule with a negative mass. When there isn't a chemically valid candidate, your notebook shouldn't produce an error so this case is worth running even though I strongly doubt it's in the test set. 


If the cause of the error isn't memory and it is a normal python error, you can proceed by wrapping your code for each prediction in a try/except block and making a default prediction in the except block. Alternatively, you can wrap smaller bits of code in the wrapper to try to try to narrow which block is throwing the error.
