A few data points from my own attempts, in case they help (fully reproducible pipeline, public LB 0.367).

The visible test.parquet overlaps train. Every one of its 400 molecules had a library match with cosine >= 0.85 against train.parquet, so local runs on it only tell you that the code works.

Add a "truth absent" control. Library matching looked great offline: +0.09 to +0.11 MRR on 234 NP-panel molecules that have references in other libraries. When I removed the true structure from the library (a class-2 proxy), the same bonus cost 0.07 to 0.30 MRR, because 35% of the NP queries have a wrong isomer with cosine >= 0.7. On the LB it netted to zero (0.360 -> 0.361). If you validate a library or lookup feature, test both cases.

Three single-change LB results, one submission each on the 0.367 base: simulator weight 1 -> 2 gave 0.360; adding the library bonus gave 0.361; pool-first ordering (NP catalogue + train structures first, PubChem candidates at fixed slots) gave 0.345.

With about 130 public molecules I treat anything within +/-0.02 as noise.
