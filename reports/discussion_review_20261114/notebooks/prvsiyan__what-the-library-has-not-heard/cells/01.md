## How the replay is built

- **Queries.** MassBank records from samartalwar's harmonized MassBank library whose molecule (tautomer-canonical InChIKey-14, the metric's identity) is neither in `train.parquet` nor in the training structure table: LC-ESI QTOF or QFT MS/MS, `[M+H]+` or `[M-H]-`, at least 5 peaks, at most 4 spectra per molecule. 190 molecules qualify. The true answer is the salt-free, neutral parent structure.
- **Removed.** Each query molecule's own records in the two external libraries that the final overlay reads: 3,262 MassBank records and 200 extlib spectra (127 extlib structure rows). Nothing else is removed, because no model in the pipeline was trained on these molecules. The engine's extra MassBank, MoNA and GNPS spectra are linked to training structures only, so they hold none of them.
- **Unchanged.** The 16 code cells of version 47, with two path lines pointed at the replay files: the competition folder in the session cell, and the input folder of the external-library overlay. The pinned 0.465 pipeline gets three path lines for the same purpose, and its hash is re-pinned. The replay test file has the competition's own schema; NCE collision energies are converted to eV as `NCE x precursor m/z / 500`, close to how the training file reports them.
- **Output.** `replay_results/`: MRR@25, top-1 and top-25 presence for every answer file the run writes (one per layer of the pipeline), the lists, the per-candidate evidence files, and the stage timings.
