# 11/13 可信MassBank precursor修复：真实可见查询差异检查

结论：**当前证据不支持给旧可信precursor修复单独占一个正式提交名额。** 原因是实际400分子/1213张可见谱上，完整旧AB与可信修复AB的阈值以上匹配结构变化为0。该工程修复确实能让构造的纠偏参考自匹配重新命中，但不能把自匹配接口成功当作排名增益。

## 执行边界

- 不重做produre1/2，不读truth、不评估MRR，不加载2.5M主训练谱库、不使用GPU、不训练、不下载、不创建Kaggle任务或提交。
- 使用官方本地 `test.parquet` 全部可见谱；完整实际A=200724、B=124160参考谱，固定原Alex匹配数学及正式官方身份guard。
- 对照/处理只改变 `trusted_bprec=False/True`。来源与核心脚本仍为已冻结 `external_library_variants_20261110.py` SHA `8c7b203f4fe90ccd95194f68cae5dd1afc7163119da84dd96c91e5f05df095e2`。
- 候选列表使用明确构造的合法25结构控制，`library_max=0`以观察全部未保护查询的匹配。没有重跑精确.488上游，因此最终CSV变化只是匹配接法诊断，不冒称冠军全流水线对照。

## 实际结果

| 项目 | 数量 |
| --- | ---: |
| 真实可见查询 | 400分子 / 1213谱 |
| 可信元信息且通过原loader至少3有效峰的纠偏参考 | 1281 |
| 可进入新质量窗口的真实查询 | 13分子 / 35谱 |
| 真实查询阈值以上匹配结构变化 | **0** |
| 真实查询在构造控制上的合法最终名单变化 | **0** |
| 额外构造参考自匹配 | 3条 |
| 自匹配新增阈值以上结构 | 2条 |

实际两次完整匹配均通过原core的score/proposal/final重构及输入/库文件绑定。两个新增自匹配分别来自 `[M+Cl]-`和`[M+2H]2+`参考，均实际使用了被纠正的measured precursor，cosine约1，产生合法提升。这证明实现触点有效，不证明真实可见/隐藏分子受益。

纠偏记录adduct分布：Na620、NH4 248、脱水H125+16、formate119+43、Cl35、双正电荷33、双负电荷25、K17。35条真实质量窗口查询中34条为H+、1条为Na+，没有得到新的阈值以上匹配。旧可信修复只改索引、不增加query/reference adduct gate，因此仍需防止跨adduct等质量碰撞，不能仅凭“索引元数据更正确”推断预测更正确。
