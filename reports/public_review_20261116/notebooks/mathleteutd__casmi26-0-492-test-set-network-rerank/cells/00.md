# CASMI26 0.492 | Test-Set Network Rerank

**What this is:** [alexchilton's 0.488](https://www.kaggle.com/code/alexchilton/casmi26-lb-0-488-peaks-to-structures-network), which runs [analyticaobscura's *casmi-2026*](https://www.kaggle.com/code/analyticaobscura/casmi-2026): the public
spectrum-to-structure pipeline plus a **test-set molecular network** step. **One change of ours:** the network weight
`LAM` **0.25 → 0.35**, which scored **0.492** on the public leaderboard.

**The network step:** test spectra with modified cosine ≥ 0.6 (≥ 6 matched peaks) are linked; each candidate gains `w⁴ × Tanimoto`
to the top-5 candidates of its linked neighbours, and the list is re-ordered by `z(−log rank) + LAM · z(neighbour score)`.
Related molecules in the test set vote for structurally similar answers.

| network weight `LAM` | 0 (no network) | 0.15 | 0.25 | **0.35** | 0.50 |
|---|---|---|---|---|---|
| public leaderboard | 0.487 | 0.487 | 0.488 | **0.492** | 0.484 |

**Tried and dropped:** a learned re-ranker of the final candidates, fitted on Enveda-180 molecules that are absent from the training
library. It looked strong there (MRR 0.27 → 0.38) but scored 0.08-0.17 on the board: with no library hits in its training set, it
learned to distrust the pipeline's list, which is usually right on the real test.

Run with **GPU T4** on and internet off. The commit takes a fast path; the scoring rerun on the hidden test runs every stage.
