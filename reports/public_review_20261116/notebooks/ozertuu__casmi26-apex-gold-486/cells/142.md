## 06 · Neural Scorers: Learning a Spectrum–Structure Match

The pretrained spectrum model projects experimental MS/MS and molecular fingerprints into comparable representations. The public **scorer v80** provides a second learned view of the same candidate set. Their scores complement the original engines, while the consensus controls how much the neural evidence can move each candidate.

Using multiple spectra from one molecule matters: different collision energies and adducts reveal different fragments, so evidence accumulated across acquisitions can be more informative than a single peak list.
