## 08 · Provenance: Useful Context, Potential Bias

Where a candidate came from can be informative. A structure independently recovered by several catalogs or engines has a different evidence profile from one supported by a single source. Yet database membership also reflects **which compounds have been studied most**, not necessarily which one generated the query spectrum.

Provenance therefore deserves a controlled role rather than automatic promotion. The selected public ranking configuration leaves this optional correction disabled.
