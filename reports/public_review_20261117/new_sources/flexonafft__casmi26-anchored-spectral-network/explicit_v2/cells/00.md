# CASMI26: Anchored Spectral Network

## Anchor-weighted test-set network

Iteration v2 on top of v1 (the 0.492 network pipeline). Only the N-1c cell changes; every other cell is v1.

N-1c links test spectra with modified cosine >= 0.6 and lets each list's candidates collect Tanimoto votes from the
top-5 answers of its neighbours. All neighbours vote alike, and any rank 1 can move. Two changes:

- **Anchors.** A neighbour whose best spectral-library match reaches `ANCHOR_LIB` (0.9) is a near-certain identification:
  it votes only with its rank 1, and its edge weight is multiplied by `ANCHOR_W` (2.0). Other neighbours vote as before.
- **Protected leaders.** A list whose own library match reaches `PROTECT_LIB` (0.9) keeps its rank 1; the network only
  reorders ranks 2-25 there, as every other overlay in this pipeline already does for library-confirmed leaders.

`LAM` 0.35 and `TAU` 0.6 are unchanged. Library matches come from `LIB_MAX` of the final layer (neural candidate
features), else from `frozen_candidate_evidence.parquet`; when neither exists the cell runs exactly as v1's.

All pipeline code is other people's, run unchanged unless stated: Roger Johnson's
[casmi26-l4-lam035](https://www.kaggle.com/code/rogersjohnson/casmi26-l4-lam035) (network weight `LAM` 0.35, public 0.492),
analyticaobscura's [casmi-2026](https://www.kaggle.com/code/analyticaobscura/casmi-2026) (N-1c in-test network rerank),
the extlib overlay, romanrozen's v8 mass rule, popwenman's v80 scorer, and the lineage credited in the sections below
(busyaprime m1, Spectral Parallax, From Peaks to Structures, PubChem + Neural025, Dmitrii Gluzdov's assets).
