# CASMI26 LB 0.488 | Peaks to Structures + Network

**This version is [analyticaobscura's *casmi-2026*](https://www.kaggle.com/code/analyticaobscura/casmi-2026), run on our account.**
analyticaobscura's notebook is our previous version (0.487) plus one code cell, N-1c, which runs before the external-library overlay:
- test spectra are linked when their modified cosine is >= `TAU` 0.6 with >= 6 matched peaks;
- each of a molecule's top-25 candidates gains w^4 x Tanimoto to the top-5 candidates of its linked neighbours;
- the new order is z(-log rank) + `LAM` 0.25 x z(neighbour score); on any exception the submission is left unchanged.

The inputs and the docker image are the same as in our previous version.
It scored **0.488** on our account (submission 58314720, 2026-11-13), against 0.487 for our previous version.
We measured the same rerank offline before (last rows of the next table): -0.0033 panel MRR. The board disagreed, by +0.001.

What the rest of the code is:
- popwenman's Gold Apex V22 (romanrozen v9: zz3t3rn41's Gold Apex Version 22 plus a timsTOF mass-accuracy prior, `V8 = 'MASS'`), with `POP_W, SPEC_W` 0.10 -> 0.12;
- [popwenman's scorer kernel *casmi26-scorer-train-v80*](https://www.kaggle.com/code/popwenman/casmi26-scorer-train-v80), attached as guhongbin did;
- ozertuu's external-library rank-1 overlay at `TAU = 0.80`: a measured reference spectrum within 10 ppm + 0.002 Da, cosine >= `TAU`, at least 4 matched peaks, promotes its structure to rank 1 unless the pipeline's own library match is already >= 0.90;
- the libraries are [Takumu Hata's casmi26-extlib](https://www.kaggle.com/datasets/takumuhata/casmi26-extlib) and [samartalwar's MassBank harmonized library](https://www.kaggle.com/datasets/samartalwar/casmi-2026-spectral-library-massbankharmonized) (rows flagged `is_casmi_subset` are dropped).

That work is analyticaobscura's, guhongbin's, popwenman's, ozertuu's, Takumu Hata's, samartalwar's, heliosli's (the direct-hit promotion rule), romanrozen's and zz3t3rn41's, built on bgunshui's neural ensemble, Baidalin Adilzhan's midx notebook, Kunal Desale's MID notebook, busyaprime's merge and the authors credited further down.
Everything from the next section down is their notebook, so "we" and "our" below mean its authors.
Every dataset and kernel it reads is public. The commit run takes the authors' fast path; the scoring rerun on the hidden test runs in full.
