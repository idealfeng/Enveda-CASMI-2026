Hello organizers. Could you please clarify the following for final-submission eligibility?

Is a model fine-tuned from an officially released checkpoint (for example a DreaMS-derived model) permitted, when the checkpoint's own pretraining data is not fully documented?
Are public datasets permitted that contain training rows or features produced by a participant's own simulation code, when that code is not published?
Must a final submission be reproducible end-to-end from the competition data and openly documented resources?
Could a score relying on such artifacts be removed retroactively, and if so, on what basis?

Comment: David Healey

Officially released DreaMS checkpoints are fine to use.  


  Must a final submission be reproducible end-to-end from the competition data and openly documented resources?

  Yes.  But if there is some technicality about that question, happy to hear it out. 

  Could a score relying on such artifacts be removed retroactively, and if so, on what basis?
  We reserve the right to  disqualify and removed from the leaderboard solutions that are not in compliance with the rules.
